# 手写笔记

这里用来放课堂手写笔记、草稿推导和扫描版 PDF。把 PDF 文件放到 `docs/handwritten/` 目录后，就可以用下面的组件预览。

## 使用方法

```html
<div class="evelina-pdf-preview" data-src="../handwritten/文件名.pdf" data-title="笔记标题"></div>
```

例如，如果你放入：

```text
docs/handwritten/physics-note.pdf
```

就在本页写：

```html
<div class="evelina-pdf-preview" data-src="../handwritten/physics-note.pdf" data-title="大学物理手写笔记"></div>
```

预览框下面会自动出现“新窗口打开”和“下载 PDF”两个入口。
